E-Commerce Backend Capstone (Spring Boot REST API)

Internship: Codomax Digital Solutions — Java Development Track (Module 06)

Architecture: Controller (StoreController), Service (StoreService), Validated Models (Product, Order), Global Exception Handling, and Relational Schema (schema.sql).

REST Endpoints

  • POST /api/products — Create a product
  • GET /api/products — List all products
  • GET /api/products/{id} — Fetch product by ID
  • POST /api/orders — Place an order with stock validation
  • GET /api/orders — List all orders
